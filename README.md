# Python Calculator

A simple typed calculator for Programming with Python (IE University).

## Functions

- `add(a, b)`
- `subtract(a, b)`
- `multiply(a, b)`
- `divide(a, b)`

## How to run

```bash
uv run python src/calculator.py
```

## Errors

- If an input is not a number, the function raises `TypeError`.
- `divide(a, 0)` raises `ValueError`.
